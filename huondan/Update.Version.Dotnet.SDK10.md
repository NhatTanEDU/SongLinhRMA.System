CLI (winget): Mở PowerShell dưới quyền Administrator.

Action: 
1. Gõ lệnh winget install Microsoft.DotNet.SDK.10 
2. Nhấn Y (Yes) nếu được hỏi đồng ý điều khoản.
3. Sau khi chạy xong, bắt buộc tắt và mở lại PowerShell/IDE, lệnh dotnet build sẽ chạy qua không còn báo lỗi.
Ghi chú: Nếu bạn muốn tải thủ công bằng file .exe, vào link https://dotnet.microsoft.com/download > Chọn .NET 10 > Tải bản x64 Installer
